# RequestPort mark

An arrow handing a request over, and two fading echoes carrying it into the space that
receives it — evenly spaced, inside a tile shaded from the surface colour to the ground.

| File | Use |
|---|---|
| `requestport-icon.svg` | The icon. Also `apps/web/src/app/icon.svg`. |
| `requestport-icon-1024.png` | The same at 1024 × 1024, for stores, social and anywhere SVG is not accepted. |

`apps/web/src/app/apple-icon.png` is the square version iOS rounds itself.

Colours, from `packages/theme`: terracotta `#E66A45` (the accent), surface `#232B30` to
ground `#07090A`.
